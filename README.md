# نظام SaaS متعدد المستأجرين للمستشفيات (مشروع التخرج)

معمارية: Cloudflare Pages + Pages Functions + D1.
المرحلة الحالية: نمط العزل 1 (جداول مشتركة بعمود `tenant_id`).

## هيكل المشروع

| المسار | الوظيفة |
| --- | --- |
| `schema/shared.sql` | مخطط قاعدة البيانات |
| `lib/auth.js` | تشفير كلمات المرور (PBKDF2) وتوقيع التوكن (JWT) |
| `lib/repo.js` | طبقة الوصول للبيانات، نقطة تبديل نمط العزل |
| `functions/_middleware.js` | التحقق من التوكن وحالة المستخدم والمستشفى |
| `functions/api/*` | الواجهات: الدخول، الإعداد، المستشفيات، المرضى |
| `public/index.html` | لوحة اختبار بسيطة تعمل من الجوال |
| `tests/` | اختبارات العزل والأمان |

## قاعدة العزل الأساسية

معرّف المستشفى (`tid`) يأتي من التوكن الموقّع فقط، ولا يُقرأ من جسم الطلب أو الرابط أبدًا.
وفوق ذلك، المفاتيح الأجنبية المركبة `(tenant_id, id)` في القاعدة تمنع ربط سجلات من مستشفيين مختلفين.

## النشر من الجوال (بدون بيئة محلية)

1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. في Cloudflare: **Workers & Pages** ثم **Create** ثم **Pages** ثم **Connect to Git**، واختر المستودع.
   - Build command: اتركه فارغًا
   - Build output directory: `public`
3. أنشئ قاعدة بيانات: **Storage & Databases** ثم **D1** ثم **Create**، باسم مثل `hospital-db`.
4. افتح **Console** في القاعدة، والصق محتوى `schema/shared.sql` وشغّله.
5. في مشروع Pages: **Settings** ثم **Bindings** ثم **Add** ثم **D1 database**:
   - Variable name: `DB` (بالحروف الكبيرة تمامًا)
   - اختر `hospital-db`، وكرر ذلك للبيئتين Production وPreview.
6. في **Settings** ثم **Variables and Secrets** أضف سرّين (Secret):
   - `JWT_SECRET`: نص عشوائي طويل (32 حرفًا على الأقل)
   - `SETUP_KEY`: مفتاح تختاره لإنشاء مدير المنصة
7. أعد النشر (Retry deployment) كي تُحمَّل الإعدادات.
8. افتح الموقع: اضغط «أول مرة؟»، أنشئ مدير المنصة، ثم سجّل الدخول برمز `platform`، وأضف مستشفى، ثم سجّل الدخول بحساب مديره وجرّب إضافة المرضى.

لا تضف ملف `wrangler.toml` الآن، فوجوده يجعل Cloudflare يتجاهل الإعدادات التي ضبطتها من لوحة التحكم.

## الصلاحيات (RBAC)

المصدر الوحيد: `lib/permissions.js` (كتالوج 16 صلاحية + افتراضيات 4 أدوار). يقرؤه الخادم وتعرضه الواجهة.
- أقل صلاحية لكل دور، وفصل مهام: المدير لا يقرأ السجل الطبي ولا يحصّل المال، والطبيب لا يسجل المرضى.
- تخصيص لكل شخص (منح وسحب) من «الصلاحيات» في قائمة الموظفين، والسحب يغلب المنح.
- الصلاحيات الحساسة (`staff.manage` و`audit.view`) لا يمنحها إلا مدير المنصة، وصلاحيات المديرين يعدّلها مدير المنصة وحده.
- الصلاحيات تُحسب في كل طلب من القاعدة، فأي تعديل يسري فورًا على الجلسات الجارية.

الترحيلات بالترتيب: `schema/shared.sql` ثم `002_appointments.sql` ثم `003_security.sql` ثم `004_permissions.sql`.
